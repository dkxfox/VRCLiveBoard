## 1. 七问(D0)

1. **谁在什么场景下用**: 开 VRChat 的 B站主播 —— 直播时观众的弹幕/礼物/SC/上舰要能出现在 VRChat 聊天框里, 不用回头看屏幕。
2. **要不要占聊天框**: 要。弹幕 **75** / 礼物 **80** / SC **88** / 上舰 **92**; 普通消息 8 秒、高价值"保持展示"15 秒(均可调)。与歌曲(30)、电脑状态(10)、公告板(5)冲突时**抢占**; 与来源保护(截图翻译/翻译字幕)**让路排队**; 当前显示优先级 ≥85 时让路; 被同一个非保护来源挡住超过 20 秒抢一次(卡死保护, 防"排队到过期全丢")。直播间信息走数据源(优先级 **12**), 不抢弹幕。
3. **新配置项**: 全部在 `config.json` 的 `plugins["bilibili-live"]` 段(不在配置根, 不污染全局默认值)。四个凭据 + `autoStart`(true) / `ignoreSelf`(true) / `showUname`(true) / `prefix`('') / `throttleMs`(1500) / `ttlMs`(8000) / `holdEnabled`(true) / `scHoldMs`·`giftHoldMs`·`guardHoldMs`(15000) / `maxLen`(100) / `showRoomTitle`(true) / `showRoomId`(true) / `showRoomPopularity`(**false**) / `roomInfoPrefix`('【直播间】') / `roomInfoPriority`(12) / `roomInfoIntervalMs`(60000)。**插件默认不启用**(需控制台红窗授权+启用); 另有 13 个"可改 config.json 但还没做成界面字段"的键, 已在 `test/settings.test.js` 输出里如实列出。
4. **新端点**: 主体**零新端点** —— 复用既有 `POST /api/plugins/config`(保存设置)、`POST /api/plugins/call`(测试连接/预览/状态/热重载)、`GET /api/plugins`(设置字段与掩码)。插件机制侧新增一个只读能力 `ctx.chatbox.current()`(桥判断"该抢还是该排队"必须知道屏幕现状)。门禁级别: 与既有 `/api/plugins/*` 相同(本机控制台)。
5. **新依赖**: **无**。Node 内置 `WebSocket`/`zlib`(含 brotli)/`crypto`/`fetch`; `engines.node` 已提到 `>=22`(全局 WebSocket 要求)。体积: 插件目录 ~120KB(`test/` 已进 pack-exclude, 不进包)。
6. **失败降级**: 缺凭据 → 不连接并点名缺哪个; `start` 失败 → 人话错误(带响应键名) + 明确原因; 平台停推(`_INTERACTION_END`)→ 5 秒后自动重新开局; 长连接断开 → 指数退避(2s→60s)并换服务器; 公开接口取热度失败 → 只少"热度"那一段; 被占屏者卡住 → 20 秒后抢一次, 期间丢弃**必记日志并写明原因**。
7. **不做什么**: 不做社区(逆向)协议通道的随包分发; 不做观众数据采集/落库(队列只在内存, 重启即丢 —— 与"不采集不落库"口径一致); 不做"礼物触发 OSC 动作"(玩法层, 另立卡); 不替用户保管凭据(只读本机 `config.json`, 界面不回显、日志不含值)。

## 2. 四张契约(D1)

### API 契约
| 端点 | 方法 | 请求 | 响应 | 错误码 | 门禁 |
| --- | --- | --- | --- | --- | --- |
| `/api/plugins` | GET | — | 插件列表(含 `settingsUi`, **密钥字段只回 set 布尔**) | — | 既有 |
| `/api/plugins/config` | POST | `{id, cfg}` | `{ok:true}`; 密钥留空=不改 | 400 | 既有 |
| `/api/plugins/call` | POST | `{id, method, args}` | 插件 `api[method]` 的返回 | 400 方法不存在 | 既有 |
| 插件 `api` | — | — | `test`(start→end, 缺凭据直接拒) / `start` / `stop` / `preview`(假事件走完整管线) / `status` / `reloadConfig` | — | — |

### 配置契约
| key | 类型 | 默认值 | 说明 | 老配置缺键时 |
| --- | --- | --- | --- | --- |
| accessKeyId / accessKeySecret / appId / roomOwnerAuthCode | text/password | '' | 官方开放平台四参数(密钥类不回显) | 视为未填, 不连接并提示 |
| autoStart | bool | true | 启用即连接 | 取默认 |
| ignoreSelf | bool | true | 不转发主播自己的消息 | 取默认 |
| showUname / prefix / maxLen | bool/str/num | true/''/100 | 文案 | 取默认 |
| throttleMs / ttlMs / highValue* | num | 1500/8000/15000 | 节奏 | 取默认 |
| holdEnabled / scHoldMs / giftHoldMs / guardHoldMs | bool/num | true/15000×3 | 高价值保持展示 | 取默认 |
| showRoomTitle / showRoomId / showRoomPopularity | bool | true/true/**false** | 直播间信息 | 取默认 |
| roomInfoPrefix / roomInfoPriority / roomInfoIntervalMs | str/num/num | '【直播间】'/12/60000 | 直播间信息显示 | 取默认 |

### 显示契约
- 优先级: 上舰 92 > SC 88 > 礼物 80 > 弹幕 75 > 直播间信息 12(接管既有的 99/95/80/70/45/40/35/30/10/5 阶梯, 新增 92/88/75/12 四档)
- ttl: 弹幕 8000ms; 高价值按"保持展示"15000ms(逐类可调, 0=用基础时长)
- 字符预算: 单条 ≤ `maxLen`(默认 100) → composer 另有 144 硬上限; 回复某人加 `@昵称 ` 前缀
- 冲突让位: 来源保护(截图翻译/翻译字幕)与"当前显示 ≥85"一律让路排队; 高价值永不因排队超时被丢

### 权限契约(插件)
```json
{ "network": ["live-open.biliapi.com", "chat.bilibili.com", "api.live.bilibili.com"], "filesystem": { "read": [], "write": [] }, "process": false, "ports": [] }
```
`api.live.bilibili.com` 只用于可选的"显示观看热度"(公开只读接口, 默认关)。

## 0.5 A0 歧义回述(先确认, 再设计)

「其他软件操控玩家动作」至少有三种读法, 实现与风险完全不同:

| # | 读法 | 实现方向 | 风险 |
| --- | --- | --- | --- |
| **A** | **别的软件 → 我们 → VRChat**: 我们对外提供一个**本机动作接口**(HTTP), 任何脚本 / StreamDeck / 脚踏 / 直播工具都能调, 驱动**本机玩家**的移动/跳跃/转身/使用/抓取/快捷菜单/静音 | 我们在主体或插件里加一个"动作输出"模块 + 本机零级接口 | 低(用户自己触发) |
| **B** | **我们自己的功能 → VRChat**: 手势/语音/键盘插件顺带能驱动动作(如"握拳=跳跃"或"一键做表情") | 同 A 的底座, 调用方是我们自己 | 低 |
| **C** | **别人/观众远程操控你**(直播互动: 观众点一下就让你跳/转身) | 需要一个**远程授权通道**(不是本机接口), 要考虑审核、限速、一键切断 | **高**: 涉及 ToS(自动化/被操控)与观感, 必须单独设计授权与红线 |

**我的建议**: 先做 **A + B**(同一套"动作输出"底座, 插件的表情/辅助都用它), **C 单独再议**(要做也必须"用户明确授权 + 一键切断 + 限速 + 只对授权对象开放")。

## 1. 七问(D0)

1. **谁在什么场景下用**(待用户确认场景优先级):
   - ① **无障碍/单手/无言势辅助**: 用外部按钮(脚踏、单手键盘、头部开关)或我们的手势, 触发移动/跳跃/转身/使用 —— 把"手柄上够不到的键"变成可自定义的触发;
   - ② **表情表达**: 一键触发 emotes 与头像参数(**不说话的人靠这个"说话"**), 与「无言势辅助」主题一致;
   - ③ **直播/他人触发**(读法 C): 观众触发动作 —— 需要单独授权设计, 默认不做。
2. **要不要占聊天框**: **不占**(动作不经过聊天框; 只有"我做了什么"这类提示才可能临时占用)。若将来要做"动作提示", 优先级 **80** / ttl **8000** / 144 截断, 与"来源保护·当前显示≥85"冲突时排队(同既有规则)。
3. **新配置项**(草案, 待定稿): `actions.enabled`(默认 **false**)、`actions.allowLocalApi`(默认 **false** —— 外部软件调用必须显式开)、`actions.maxRatePerSec`(默认 5, 限速)、`actions.panicMs`(默认 1500, 松手/断流后多久强制复位)、`actions.map`(触发 → 动作的映射表)。`config.default.json` 同步; 老配置缺键兜底同既有做法。
4. **新端点**(草案): `POST /api/actions`(`{action:'Jump'|'MoveForward'|'Emote', value, holdMs}` → `{ok, sent, resetAt}`); `GET /api/actions`(状态: 当前按下的动作、是否已复位、速率余量)。错误码: 400 参数错 / 403 未开 allowLocalApi 或跨站 / 429 超速 / 409 动作不支持。**门禁级别: 零级**(只本机)。
5. **新依赖**: **无**。发送走既有 `src/osc.js`(UDP 9000), 动作名走 VRChat 官方 `/input/*` 与 `/avatar/parameters/*`。
6. **失败降级**: 动作未确认生效 → 不做"以为发了"(如实回执); 超过 `maxRatePerSec` → 拒绝并入日志; 连接中断/用户松手 → 到 `panicMs` 强制复位(见 §2 的复位红线)。
7. **不做什么**:
   - **不操控别的玩家**(VRChat 没有这个 API, 也不该有);
   - **不做自动化/挂机/脚本化行为**(与既有红线"不做自动发言、不做按脚本刷屏"同一条: **只做人工触发、随时可断**);
   - 不做"绕过 VRChat 输入系统的注入"(不写驱动、不发模拟按键给游戏窗口);
   - 首期不做读法 C(他人远程操控), 需要时单独开卡。

## 2. 已确认的技术事实(反向通道, 有官方文档依据)

- VRChat 官方《OSC as Input Controller》明确支持**应用 → 游戏**的输入驱动, 文档原话: "you could create a program to control VRChat with your head, feet, brainwaves, a musical sequencer or just about anything else";
- **轴**(float -1~1): `Vertical` `Horizontal` `LookHorizontal` `UseAxisRight` `GrabAxisRight` `MoveHoldFB` `SpinHoldCwCcw` `SpinHoldUD` `SpinHoldLR`;
- **按钮**(int 1/0): `MoveForward` `MoveBackward` `MoveLeft` `MoveRight` `LookLeft` `LookRight` `Jump` `Run` `ComfortLeft` `ComfortRight` `DropLeft` `DropRight` `UseLeft` `UseRight` `GrabLeft` `GrabRight` `PanicButton`(开安全模式) `QuickMenuToggleLeft` `QuickMenuToggleRight` **`Voice`**(切换语音) —— 共 **32 项**(含文档标注"不确定是否有效"的两项);
- **实现红线(文档写明)**: 轴与按钮**用完必须复位**(留 `Vertical=1` 会让人一直往前走; `Jump 1` 连发只跳一次) → 我们的接口必须**自动复位**并在断流时兜底复位;
- **头像参数**: `/avatar/parameters/*` 可写入(官方例: `VRCEmote` 触发挥手/跳舞; 自定义参数由头像决定) → "一键表情"走这条;
- **兼容性**: 文档明确"有些只在桌面/VR 某一模式有效, 有些可能没什么效果" → 需要**实机矩阵测试**(这条要写进 D3 断言与验收)。

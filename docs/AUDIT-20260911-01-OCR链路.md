## 已核实无问题(不必重复排查)

1. 常驻进程不会随 app 退出变僵尸(宿主 stdin EOF + main.js 显式 stop)。
2. 指令不会在一条 stdin 上交叉(chain + 单例)。
3. stderr 不污染 stdout 协议。
4. UTF-8 双向正确(显式 UTF8 StreamReader + 每行 trim), 中文窗口标题有门禁断言。
5. 不会半行/乱码(缓冲 + setEncoding('utf8'))。
6. 失败也回一行协议, 不悬挂。
7. 无 PowerShell 命令注入(JSON 传输 / execFile 参数数组 / mode 白名单 / beep 只用常量)。
8. 窗口模式图片内存有界(先裁剪再放大)。
9. 超长行不死循环、不切断代理对。
10. 并发点击不叠加(running 立即拒绝)。
11. 常驻路径实测正常(logs/app.log 里 4 次连续 OCR 成功, 无 [capture] 告警)。

# 1.4.6 开发复盘:主要问题与固化(2026-10-05)

> 本轮从「VR 里点不着的浮层」开始,到 1.4.6「磨刀」发布结束。这里只记**真出过问题**的事,以及每条留下的**自动断言**。

## 一、主要问题(按性质分四类)

### A. 验证打错了地方(最贵的一类)
| 现象 | 真因 | 留下的断言 |
| --- | --- | --- |
| 品牌下拉首次启动是**空心胶囊**;我改完 `data-value` 就说"好了", 结果用户那里照旧 | ① 根因其实在**组件**:`dsel.js` 的值匹配不到选项时只回落到 placeholder, 而品牌下拉没给 placeholder; ② **我只验了源码, 没验用户实际在跑的包** | `dsel-behavior.js` 新增 3 条:值不在选项里→回落第一个选项 / 值被纠正为有效值 / 空值也不留空 |
| 包里混着 **10-03 的 `dsel.js`** | `make-dist` 用 `-ErrorAction SilentlyContinue` 吞掉 stage 清理失败, 而 `robocopy /E` 只覆盖不删除 → **陈旧文件原地留着** | `pack-script-check.js`:正向断言"stage 清理必须 `-ErrorAction Stop` + 有\"清不掉就中止\"分支" |

### B. 性能/健壮性:一个用户随手输入就能打垮服务端
| 现象 | 真因 | 留下的断言 |
| --- | --- | --- |
| 连按键盘 **整个窗口卡死 11 秒** | 无效拼音串让引擎的切分**组合爆炸**(它必须跑完才返回), 单线程服务端被堵死 | `ime-assert.js` 长串耗时上限 + `ime-stress.js` 五组压力(p95<=150ms) |
| 打字不跟手(每键 200~700ms) | HMM 成本随音节数线性上升, 而模糊音给**每个变体**都跑一遍 | 同上(压力测试锁住) |
| 冒烟 G4 反复失败 | **我自己**上一次被中断的冒烟跑留下孤儿进程占着 1925x 端口 | 冒烟脚本自身已报 "port released";新增的纪律:中断的冒烟必须先清进程 |

### C. 交互:VR 的物理约束被反复验证
- 会动的目标点不到 / 字号太小看不清 / 相关操作必须挨在一起 —— 用户每条反馈都落在**同一类约束**上;
- 固化在 `docs/FEATURES/F-20260929-02` 与 §"VR 三约束"里, 后续任何界面先按这三条量一遍。

### D. 我自己的流程错误
| 错误 | 后果 | 纠正 |
| --- | --- | --- |
| 门禁跑在**提交之前** | `GSYNC` 判"工作区不干净"→ 假失败一次 | 顺序固定为:**先提交, 再跑门禁** |
| i18n 锚点用了**三语同值**的键 | 键插歪(zh-CN 重复 / en 多出 / zh-TW 缺失), GI18N 报 3 条 | 锚点必须**按语言唯一**; 且不要假设"一行一语言" |
| 新增 `how` 没登记进排序表 | 比较函数算出 NaN, 候选排序崩 | 代码里已写明"新加 how 必须登记" |
| 自绘下拉用 `id` 定位(26 键与九键各一份) | 26 键的 ⇧ 永远不更新 | 改用**类名**; 并在代码里注明原因 |

# 术语表(GLOSSARY)

> 存在的唯一目的:**消除歧义**。大量返工来自双方对同一个词的边界理解不同。
> 规则:本表里的词,在会话与文档中只能按此含义使用;要表达别的意思,请换词或显式说明。

## 分发物

| 术语 | 精确含义 | 常见误解 |
| --- | --- | --- |
| **公开版** | `dist\公开版\` 下两个 zip,面向所有人,**不含任何锚点与一级密码**,免费 | 不等于"开源";源码公开与分发版是两件事 |
| **自包含包** | `VRCLiveBoard-Desktop-SelfContained-vX.zip`,自带 node_modules 与 electron,解压即用(约 211MB) | — |
| **lite 包** | `VRCLiveBoard-Lite-RequiresNode-vX.zip`,需系统 Node,首次启动自动装依赖(约 11MB) | — |
| **授权版 / 开发者申请版** | 由母狗 `authorize` 基于某个基础包生成,**内含该人专属锚点 + 一级密码 + 迷你狗** | 不是"高级版",功能相同,只是解锁了设置层级 |
| **插件更新包** | 单个插件的 zip,供已装用户替换,不含主程序 | — |
| **官方可选插件(目录)** | **只存在于打包产物**里的插件恢复备份,由 `make-dist` 从 `plugins/` 生成;仓库里只保留《说明-如何装回插件.txt》 | 不是第二份源码,不要手工同步 |
| **插件单一源** | `plugins/<id>/` 是插件代码的唯一位置;任何第二份副本都视为事故隐患 | — |
| **安全类开关** | 影响攻击面的开关(提示词防线 / JSON 结构化输出 / 输出消毒 / 脏话过滤器):**默认强制开启**,只允许一级密码持有者关闭 | 与「新功能默认关闭」不冲突:功能默认关,安全默认开 |
| **milestone 发版** | 攒够重要功能才发次版本(1.4.0);平时修 bug 与小修控制台只走补丁位 | 不是「每个功能发一版」 |

## 授权体系

| 术语 | 精确含义 |
| --- | --- |
| **母狗** | `dev-dongle\master\`,只存在于开发者机器,**永不外发**;持有主口令,能生成任何人的链 |
| **迷你狗** | 随授权版分发的解锁器,只含**某一个人**的链种子(`chain.json`),泄露只影响该人 |
| **链盐(CHAIN_SALT / SALT)** | 参与链计算的常量,**随包公开、不是秘密**;`src/devgate.js` 与 `master.js` 必须逐字一致;轮换它 = 让所有旧锚点与旧迷你狗整体作废 |
| **锚点(anchor)** | 哈希链末端值,存在使用者的 `config.json.devchain`;**单向,不可逆推出下一个码** |
| **一次性码** | 迷你狗按链逆序发放的 16 位十六进制密码,用一次作废 |
| **一级密码** | 授权版专属的八位数字(早期六位),解锁"高级设置"中的安全项;**公开版没有一级密码** |
| **开发者级** | 需一次性码解锁,可编辑脏话词库等;会话级,重启复位 |
| **授信数据** | 登记表行 + 已装锚点 + 已发迷你狗 + 已发授权包 + 母狗备份中的登记快照。**"清空授信数据"= 以上全部**,但**不含**母狗主口令与 `master.key`(要换口令必须显式说明) |

## 动作

| 术语 | 精确含义 | 是否可逆 |
| --- | --- | --- |
| **打包** | 跑 `scripts\make-dist.ps1`,产出 `dist\公开版\` 双 zip | 可逆(重跑即可) |
| **同号重打** | 版本号不变、重新生成 zip 覆盖旧文件 | 可逆,但**已分发出去的旧包收不回** |
| **发布** | 在 GitHub 建 Release 并上传资产(+ 群文件上传) | **不可逆**(下载链接一旦公开) |
| **替换资产** | 删除 Release 上的旧 zip 并上传新 zip | **不可逆**(旧资产删除后需重新构建才能恢复) |
| **轮换盐 / 密钥** | 更换 CHAIN_SALT 或 API key | **不可逆**(旧世界立即作废) |
| **清空登记表** | 把 `授权登记表.xlsx` 清成只剩表头 | **不可逆**(需按姓名重新 register) |

## 环境

| 术语 | 精确含义 |
| --- | --- |
| **用户实例** | 用户日常运行的那个进程,端口 **19190**。**任何测试都不得连它、不得杀它** |
| **测试实例** | 临时目录 + 端口 19250 / 19260 + `VRCB_USER_DATA` 隔离的进程,用完必须清 |
| **项目根** | `Z:\DeepSeek Harness工作区\VRCLiveBoard`,**唯一真相源**;不存在"上传副本"这种概念(历史上有过,是事故来源) |

## 流程

| 术语 | 精确含义 |
| --- | --- |
| **门禁(Gate)** | `scripts\checks\` 下可执行、有退出码的检查;唯一被承认的"验证" |
| **证据** | `GATES SUMMARY` 表或命令原始输出;自然语言描述不算证据 |
| **S1–S4** | S1 崩溃/数据丢失/安全;S2 主功能不可用;S3 体验问题;S4 优化建议 |
| **可逆动作** | 能用 `git revert` 或重跑脚本还原的动作 |
| **不可逆动作** | 见"动作"表中标注,执行前必须走 A0 回述确认 |

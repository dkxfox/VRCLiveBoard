## 三、关键实测结论(VRChat 侧, 已被插件利用)

| # | 结论 |
| --- | --- |
| 1 | `/dolly/Import` 接受**绝对文件路径字符串**; 导入本身不动相机; `/dolly/Play true/false` 播放/停止; 播放期间 Pose 有事件 |
| 2 | **单段关键帧 >6 会崩**(7 帧有时 `routine is null`, 8+ 必崩) → 插件自动拆成 ≤6 帧/段; 12 帧拆 6+6、10 帧拆 6+4 实测正常 |
| 3 | 拆分/临时文件**必须放在 CameraPaths 目录内**(放 %TEMP% 会崩); Import 后需等 **≥800ms** 再 Play |
| 4 | `/dolly/PlayDelayed` 读回不可靠 → 用 “Import→等待→Play”; `/dolly/Export` 会往 CameraPaths 写带时间戳的文件 |
| 5 | 播放后 `/usercamera/Lock` 可能变 true(相机被锁) → 停止时可选自动解锁 |
| 6 | 相机数值端点必须写 **float32**(整数也写 'f'), 否则读回脏值; 写后必须读回确认(以读回为准) |
| 7 | FlySpeed 历史上有“写值读回怪值”现象, 不可盲信; 本阶段未改动用户 FlySpeed |
| 8 | 相机模式: 1 本地单张 / 2 直播 / 4 本地多图层 / 5 拍立得; 3(动画)未启用、6(无人机)需模型 |

### 7.3 主要风险
| 风险 | 说明/缓解 |
| --- | --- |
| VRChat 版本依赖 | dolly 行为是逆向实测的; 新版本可能变 → EA 前在测试组 VRChat 版本上复跑回归 |
| 插件实验性 | 崩溃/边界情况可能影响体验 → 标注“实验功能”, 提供一键停用/panic 停止 |
| LAN 控制台安全 | 默认关闭 + 可选口令; 无口令=同网段可控制 → 测试组默认不开或设口令 |
| 授权体验 | 内容哈希变化会要求重新红窗授权 → EA 期间冻结版本, 减少打扰 |
| 防火墙 | 手机访问需放行 Electron 专用网络入站 → 文档给步骤 |

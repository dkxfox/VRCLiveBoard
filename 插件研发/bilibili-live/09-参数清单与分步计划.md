# 09 · 参数清单与分步计划(开工基线)

> 2026-09-20 定稿。**先确认参数, 再写代码** —— 这份文档就是后面设置面板的字段表。

## A. 凭据类(4 个) —— 只存本地 `config.json` 的插件段, 永不进仓库/日志/发布包
| 参数 | 来源 | 用途 |
| --- | --- | --- |
| `accessKeyId` | 申请通过邮件 | 请求头 `x-bili-accesskeyid` |
| `accessKeySecret` | 申请通过邮件 | 签名密钥(HMAC-SHA256), **永不打印** |
| `appId` | 创作者服务中心 · 项目详情 | `start` 入参 |
| `roomOwnerAuthCode` | 幻星右侧「身份码」 | `start` 入参 `code`(主播身份码) |

## B. 协议与运行时参数(固定, 无需用户填)
| 项 | 值 | 备注 |
| --- | --- | --- |
| API 基址 | `https://live-open.biliapi.com` | 三个端点都在这里 |
| 端点 | `/v2/app/start` · `/v2/app/heartbeat` · `/v2/app/end` | start 返回 `game_id` / `host_server_url_list` / `auth_body` |
| 签名 | 六个 `x-bili-*` 头 → `key:value` 换行拼串 → HMAC-SHA256(secret) → `Authorization` | 头顺序不可重排; 含 body 的 MD5 |
| 连接心跳 | **30 秒**(WebSocket op=2) | 漏发掉线 |
| 项目心跳 | **20 秒**(POST heartbeat, 带 `game_id`) | 与连接心跳是**两个** |
| 帧头 | 16 字节: 总长 / 头长 / protover / op / seq | 大端 |
| 压缩 | protover `2`=zlib, `3`=brotli | Node 内置 `zlib` 两种都能解 |
| 重连 | 指数退避: 2s 起, 上限 60s, 带抖动 | 风控错误码要退让, 不硬重试 |
| 超时 | HTTP 10s; 认证回应 10s 未到即重连 | |
| 弹幕服务器域名 | 由 `host_server_url_list` **动态返回** | 需按 `*.bilibili.com` / `*.hdslb.com` 白名单校验后才连 |

## C. 玩法参数(头顶弹幕) —— **这部分需要你确认默认值**
| 参数 | 建议默认 | 说明 |
| --- | --- | --- |
| `enabled` | 开 | 总开关 |
| `prefix` | `【B站】` | 前缀, 可清空 |
| `showUname` | 显示 | 格式: `【B站】昵称: 内容`; **只显示昵称, 不带 UID**(与既有插件口径一致) |
| `ttlMs` | 8000 | 每条显示时长(项目里截图提示也是 8s 量级) |
| `priority` | 75 | 高于字幕(40)/截图区域(45), 低于插件欢迎(90)与截图翻译(85) |
| `maxLen` | 100 | 单条截断长度(聊天框上限 144 字符/9 行) |
| `minIntervalMs` | 1500 | 进聊天框的最小间隔(限流, 防止弹幕刷屏把公告板挤没) |
| `queueMax` | 20 | 队列上限, 超出丢最旧 |
| `useSwearFilter` | 开 | 复用项目既有脏话过滤器 |
| `ignoreEmpty` | 开 | 忽略空白弹幕 |

## D. 落盘与权限
- 配置段: `config.json` → `plugins['bilibili-live']`(插件设置机制写入; UI 用 password 类型 + 掩码);
- `manifest.permissions.network`: `live-open.biliapi.com` / `api.live.bilibili.com` / `api.bilibili.com`;
  (弹幕服务器域名由官方接口返回, **动态校验白名单后再连**, 不写死也不无脑连)
- 不声明 `process`、不声明文件写入 —— 这个插件只做"联网取事件 + 推聊天框"。

## E. 分步计划(每步都能单独验证)
| 步 | 内容 | 验证方式 | 状态 |
| --- | --- | --- | --- |
| 1 | 参数清单与本计划 | 本文档 | ✅ 本轮 |
| 2 | **帧编解码**(16 字节头 + zlib/brotli + 半包) | 本地夹具单测(纯离线) | ✅ 本轮 |
| 3 | 签名与 HTTP(不联网): 拼头/拼签名串/构造 start 请求 | 假密钥单测: 断言签名串逐字正确 | ⏳ |
| 4 | wss 连接 + 认证 + 双心跳 + 重连退避 | 本地假服务器(自己实现一个说同样帧协议的 server) | ⏳ |
| 5 | CMD → `BilibiliEvent` 归一化 | 真实消息样本夹具(弹幕/礼物/SC/上舰各一条) | ⏳ |
| 6 | 推送到聊天框(优先级/TTL/分片/限流/屏蔽词) | 隔离实例冒烟 + 手工触发 | ⏳ |
| 7 | 设置面板(掩码输入 + 测试连接) + 门禁 + 文档 | 四参数填真值, 收第一条真弹幕 | ⏳ |

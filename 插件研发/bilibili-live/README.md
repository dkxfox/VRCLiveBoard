## 一句话结论
- **给所有人用 → 走官方直播开放平台**(实名认证即可申请, 审核宽松; 社区协议属于"逆向非公开接口", 随产品分发有明确法律风险)。
- **想两条路都留 → 共享上层、隔离下层**: 玩法层只认统一事件模型; 官方 adapter 进包, 社区 adapter 只在你本机(pack-exclude 排除, 不发布)。
- **体积不是问题, 但别引第三方库**: 自实现约 600~900 行 / 30~50KB, 用 Node 内置 `WebSocket` + `zlib`(含 brotli) + `crypto`(Hmac) + `fetch`, **零新增依赖**。

## 顺带记下的小坑(与本插件相关的既有问题)
- `package.json` 写的是 `engines.node >= 18`, 但项目里已有代码用**全局 `WebSocket`**(歌词插件 `cdp.js`) —— 它要 Node **21+ / 22 才稳定**。
  也就是说 Node 18/20 用户跑歌词插件会失败。建议把 engines 提到 `>=22`(本机是 Node 24), 而不是引入 `ws` 依赖。

# 08 · 开通四步(含"主播身份码"在哪拿)

> 整理 2026-09-20。来源: 第三方完整接入教程(郊狼 BLive 教程)+ 官方 Godot 插件文档(godot-open-blive)+ 官方签约实现(blivedm), 三处互相印证。

## 第 0 步 · 注册开发者 ✅ 已完成
到 [哔哩哔哩直播开放平台](https://open-live.bilibili.com/) 申请开发者认证 → 认证通过后**邮件收到**:
- `access_key_id`
- `access_key_secret`

官方提醒原话: **"不要向任何人透露你的 access_key_id 和 access_key_secret"**。

## 第 1 步 · 创建项目 ✅ 已完成
进入 [创作者服务中心](https://open-live.bilibili.com/open-manage) → 创建**互玩项目** → 在**项目详情**里拿到:
- `app_id`(项目 ID, 一长串数字)

## 第 2 步 · 拿"主播身份码"(= `room_owner_auth_code`) ← 你现在在这一步
**路径**: 用**开播的那个 B 站账号**登录 [幻星(互动玩法中心) play-live.bilibili.com](https://play-live.bilibili.com/)
→ 页面**右侧有「身份码」**入口 → 点开即可查看/复制**主播身份码**。

要点:
- 身份码属于**主播本人**(与直播间绑定) —— 如果不是你自己的号开播, 需要**让那位主播登录幻星拿码**;
- 它和 secret 一样属于**凭据类信息**, 同样不要外传、不要截图发群;
- 有效期/是否一场一码**未确认** → 若 `start` 报错, 先**重新取一次码**再试;
- 若幻星页面找不到「身份码」入口: 确认①账号是**开播账号**、②项目类型是**互玩项目**、③直播间**正在开播**; 仍不行就把"互玩项目 + 身份码入口"这两个关键词发给开放平台客服问路径。

## 第 3 步 · 四个参数填进本地配置(插件设置页, 待开发)
| 参数 | 值 |
| --- | --- |
| `access_key_id` | 邮件里那串 |
| `access_key_secret` | 邮件里那串(掩码显示, 永不打印) |
| `app_id` | 项目详情里的数字 ID |
| `room_owner_auth_code` | 幻星「身份码」 |
→ 然后点插件的「测试连接」: start → 连 wss → 收到第一条弹幕就算通。

## 安全约定(插件侧已定死)
1. 四个值只写本地 `config.json` 的插件段(已 gitignore + 已进打包排除清单, **永不进发布包**);
2. 日志里只允许出现 `access_key_id` 的前 4 位, `access_key_secret` **永不打印**;
3. 仓库、文档、聊天记录里**不写实际值**(本文档只写"怎么拿", 不写"拿到的值");
4. 一旦怀疑泄漏 → 立刻到开放平台重置密钥。

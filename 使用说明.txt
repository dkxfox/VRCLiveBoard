============================================================
  一、这是什么
============================================================
VRCLiveBoard 是一个 Windows 小工具。把它开着,你玩 VRChat 的时候,
别的玩家能在你头顶的聊天框看到:

  · 电脑状态: CPU/显卡温度、内存占用、网速(自动刷新)
  · 正在播放的歌 / 视频的标题(支持网易云歌词精确同步)
  · 你写好的公告文字(自动轮播)
  · 语音字幕: LiveTranslate 实时听译的译文
  · 游戏截图翻译: 游戏里的文字截图 → 识别 → 翻译

你自己在游戏里也能看到,就显示在头顶聊天框的位置。
所有显示都是"直发"模式: 不弹窗、不打断、不播放提示音。

------------------------------------------------------------
  二、快速上手(3 分钟)
------------------------------------------------------------
1. 启动软件: 双击 启动.bat(网页版)或 启动桌面版.bat(独立窗口)。
2. 进 VRChat → 打开菜单(Action Menu)→ 选项(Options)→ OSC →
   选 启用(Enabled)。这一步每个账号只需要做一次。
3. 看控制台最上面的状态卡: 圆点变绿 = 已连上游戏, 头顶开始显示。

忘了怎么用时, 点控制台右上角的「📖 新手引导」按钮随时重看。

------------------------------------------------------------
  三、启动方式与两个安装包的区别
------------------------------------------------------------
安装包分两种, 功能完全一样, 按需选一个解压即可:

  自包含版(Desktop-SelfContained, 约 211MB):
    · 自带全部运行环境, 不需要安装任何东西, 解压即用;
    · 双击 启动桌面版.bat 或 启动.bat。

  轻量版(Lite-RequiresNode, 约 11MB):
    · 体积小, 需要电脑已安装 Node.js;
    · 第一次启动会自动补齐缺失的组件(需要联网)。

启动方式:
  方法一(网页版): 双击 启动.bat, 自动打开浏览器控制台。
  方法二(桌面版): 双击 启动桌面版.bat, 弹出独立窗口(内容相同)。
    关窗口只是藏到托盘(右下角小图标), 右键托盘图标选"退出"才是
    真正关闭。高级设置里可以开关"命令行窗口"的显示。

------------------------------------------------------------
  四、控制台详解
------------------------------------------------------------
打开控制台后, 从上到下依次是:

【页头】
  · 标题下方显示当前控制台地址(如 http://127.0.0.1:19190), 可收藏;
  · 右上角: 「📖 新手引导」按钮(常驻)+ 语言切换(简体/繁體/English)。

【状态卡】
  · 顶部圆点: 绿色 = 已连上游戏; 黄色 = 游戏开着但 OSC 没开;
    灰色 = 游戏没开(或日志未更新)。
  · "当前聊天框内容": 现在你头顶显示的文字; 下方小字显示
    来源、优先级、剩余显示秒数(看懂"为什么是这条");
  · 输入框 + 发送到聊天框: 临时说一句话, 头顶立刻显示, 8 秒后
    自动恢复原内容;
  · 一键诊断 + 复制报告: 出问题时点一下, 把报告发给开发者。

【健康总览卡】
  一屏看全: VRChat/OSC 状态、UDP 9000 端口状态(绿 = VRChat 在听;
  红 = 被别的程序占用并给出程序名; 灰 = 游戏没开或没开 OSC, 属正常)、
  控制台地址、OSC 目标、Python(听歌显示)、LiveTranslate(翻译)、
  插件启用数与报错数。"复制体检报告"按钮可直接把纯文本报告发给
  开发者。每 30 秒自动刷新。

【公告板页面卡】
  · 头顶自动轮播的文字就在这里编辑, 点"添加页面"新建;
  · 每页最多 144 字符, 可以换行, 最多显示 9 行;
  · 可用变量(实时替换): {cpu_util} CPU使用率%  {cpu_temp} CPU温度
    {gpu_util} 显卡使用率%  {gpu_temp} 显存温度  {gpu_mem} 显存占用
    {mem_used}/{mem_total} 内存已用/总  {net_down}/{net_up} 网速
    {song}/{artist}/{album} 正在播放的歌(需开启“正在播放的歌”功能) {time}/{date} 时间日期;
  · 点"保存到 config.json"生效; 轮播间隔(秒)可调;
  · 页面太多时: 点标题行收起整卡; 点每页头部折叠单页(折叠后显示
    第一行预览); "全部折叠/全部展开"一键整理; 每页头部还有
    ▲上移 / ▼下移 / ⧉复制本页 / 删除。

【翻译系统卡】(详见第五节)
  共用同一个翻译服务(LiveTranslate)的两个功能:
  🎙️ 语音翻译(字幕): 实时听译的译文同步到头顶;
  📷 截图翻译: 游戏画面文字截图 → 识别 → 翻译。

【环境检测卡】
  缺什么补什么, 一键搞定:
  · 运行环境(Node): 程序本体, 已内置;
  · 听歌显示(Python): 显示歌名需要, 可选; 缺了点"安装";
  · 翻译服务(LiveTranslate): 语音字幕 + 截图翻译共用(见第五节)。

【功能开关卡】
  每一行是一个功能, 前面的勾随时开关:
    hardware      电脑状态(优先级默认 10)
    media         正在播放的歌(优先级 30)
    pages         公告板轮播(优先级 5)
    livetranslate 语音字幕(优先级 40)
    ocrregion     屏幕文字识别(默认关, 优先级 45)
  优先级规则: 多个功能同时有内容时, 数字大的显示在头顶。
  默认梯子: 公告板 5 < 电脑 10 < 歌 30 < 字幕 40 < OCR 区 45;
  插件欢迎(90)与截图翻译(85)会临时盖过其它, 结束自动恢复。
  优先级列可直接改数字, "恢复默认优先级"一键还原。

【插件卡】(详见第七节)
  插件完全自由管理: 安装/授权/启用/停用/删除/设置都不需要密码,
  安装新插件时会有红色警告窗 + 5 秒倒计时确认; 声明进程执行或
  AI 能力的高危插件还需输入插件名确认。卡片顶部有插件安全策略
  五个下拉(0 级可看、可单向收紧; 放宽需一级密码, 见第八节)。

【高级设置】拆成四张卡, 点标题展开:
  常规: 开机自启 / 显示命令行窗口 / 脏话过滤器开关(默认开, 零级
    可关)/ 配置备份与恢复(需一级密码)/ 退出与快速重启。
  网络端口: OSC 发送端口(保存即生效)/ 控制台端口(保存后需快速
    重启)/ 端口体检(见第九节)。
  安全与权限: 密码门禁(见第八节)。
  日志与信息: 运行日志(自动刷新 4 秒、关键词过滤、只看错误/警告、
    一键复制)、三个小提示、版本号。

------------------------------------------------------------
  五、翻译系统与 LiveTranslate
------------------------------------------------------------
本程序的翻译功能都建立在同一个翻译服务上: LiveTranslate
(一款免费的实时翻译软件)。装一次, 两个功能都用:

  ① 语音翻译(字幕): LiveTranslate 实时"听语音 → 出译文",
     本程序把译文自动同步到你的头顶聊天框;
     - 开关: 翻译系统卡里的 🎙️ 复选框(与功能开关表的"语音字幕"
       是同一个开关);
     - 前提: 环境检测卡里装好 LiveTranslate 并开启一个翻译。

  ② 截图翻译: 游戏里有看不懂的文字? 点"截图并翻译":
     - 聊天框出现倒计时(带提示音), 把视角对准要翻译的文字;
     - 到点自动截图游戏窗口中央区域, 识别后翻译并显示;
     - 识别方式: 自动(有 API Key 用视觉模型, 否则本地 OCR)/
       视觉模型(更准, 需 API Key)/ 本地 OCR(免费, 略糙);
     - 视觉模型设置: 接口地址(默认 DeepSeek, 支持 Ollama / LM Studio
       等本地模型)、密钥(本地地址可留空)、模型名;
     - 截图区域: 窗口/指定区域/全屏三种模式, "可视化调整"可拖框选;
     - 倒计时/显示时长/循环次数可调;
     - AI 安全防护: 提示词防线 / JSON 结构化输出 / 输出消毒三道开关
       默认全开(截图里的文字可能是别人设计的"注入攻击", 详见第八节)。

如何安装 LiveTranslate:
  1. 环境检测卡里点"下载 LiveTranslate", 打开作者合集页下载;
  2. 解压运行一次, 按首次引导配置好翻译模型;
  3. 回到控制台点"重新检测", 显示"已配置"即可。

------------------------------------------------------------
  六、网易云歌词精确同步(CDP)
------------------------------------------------------------
装了"网易云歌词"插件(官方可选插件)后, 聊天框会按播放进度显示
当前歌词(原文 + 译文)。

普通模式: 客户端不报告进度, 插件用时钟估算(略有偏差, 拖动
进度条后会错位, 下一首自动恢复)。

精确同步模式(推荐, 拖动进度条/暂停/切歌全同步):
  1. 把 官方可选插件\netease-lyrics 文件夹复制到 plugins\(或直接
     运行其中的 一键部署.bat, 会自动复制 + 在桌面创建快捷方式);
  2. 在插件页授权并启用"网易云歌词"(首次点红色授权窗确认),
     同时确认功能开关里的"正在播放的歌"开着;
  3. 启动网易云: 推荐在插件面板点「用调试端口启动网易云」一键
     完成(自动退出旧实例并带调试端口重启); 也可以完全退出网易云
     (托盘右键→退出)后用桌面的"网易云音乐-歌词同步"快捷方式启动
     (插件连不上时会自动在桌面创建这个快捷方式)。

插件面板里可调: 每行显示秒数 / 显示译文 / 节奏模式(按歌曲节奏
自动换行)/ 顶部歌名 / 优先级 / CDP 端口。点"查看状态"能看到
"CDP: 已连接 进度 x/y"就是精确模式生效了。
用普通图标启动网易云也没事, 插件自动退回时钟模式。

------------------------------------------------------------
  七、插件系统
------------------------------------------------------------
插件 = 乐高扩展, 可以自由安装/停用/删除, 全部不需要密码。

安装方式:
  1. 把插件文件夹放进程序目录的 plugins 文件夹, 或
  2. 在插件卡填 zip 完整路径点"导入"(自动解包校验)。

安全:
  · 新插件首次启用必须通过红色警告窗 + 5 秒倒计时确认(请只安装
    来源可信的插件); 声明进程执行或 AI 能力的高危插件还需输入
    插件名确认;
  · 安装有路径穿越/超大文件等防护; 插件崩溃不会拖垮主程序。
  · 插件安全策略(插件卡顶部, 0 级可见): 默认档对正常
    插件无感 —— 外网按插件声明的域名放行、进程执行按红色警告窗
    确认、文件读写限制在插件自身目录(敏感文件如 config.json 永拒);
    审批会校验插件代码内容, 改动代码需重新授权。想更严时可选收紧档:
    仅本机网络 / 全禁网络 / 全禁进程 / 全禁读写, 保存后立即生效。
    策略对所有人可见, 无需密码即可"单向收紧"或"恢复默认"(公开版也不会被
    自己锁死); 放宽到更宽松的非默认值才需要一级密码。
    插件的越权尝试(含绕过接口直接调用系统模块)都会写进运行日志。
  · 插件 AI 能力(ctx.ai): 插件要用 AI 时不需要自带密钥 —— 声明
    manifest.ai 后经主体统一调用, 复用你的 AI 配置(接口地址/密钥/模型)
    与三道防线(提示词防线/结构化输出/输出消毒), 密钥不会给插件看到;
    每插件 5 秒节流防烧 token; 插件卡里可用"插件AI"策略收紧为
    仅本机接口(localOnly, 如本机 Ollama 免费跑)或全禁(off)。

随包插件:
  · 好友欢迎: 指定好友进房显示专属欢迎语(支持 Excel 批量名单);
  · 定时公告: 常规轮播 + 整点/半点播报 + 指定日期时间的特殊公告
    (支持 Excel 批量管理)。

官方可选插件(在 官方可选插件 文件夹, 复制到 plugins 即装):
  · 网易云歌词: 见第六节;
  · 天气播报: 城市天气轮播(内置国内 46 城 + 国际 32 城预设)。

误删插件? 在"官方可选插件"文件夹里找回(复制回去即可)。

------------------------------------------------------------
  八、设置保护(密码门禁)
------------------------------------------------------------
高级设置 → 安全与权限, 分三级:

  🔓 零级(默认, 无需密码): 所有常规功能, 包括脏话过滤器开关、
     网络端口、公告板、插件管理、插件安全策略的单向收紧。

  🔒1 一级密码(高级设置): 每份授权版自带一个专属的八位数字密码
     (早期版本为六位, 同样有效), 人人不同; 公开版没有一级密码。
     解锁后可调整:
     · AI 安全设置(提示词防线 / JSON 结构化输出 / 输出消毒)
     · AI 安全词库与脏话词库的查看、加词
     · 配置备份 / 恢复
     · 插件安全策略的放宽(收紧 0 级即可, 见第七章; 含插件 AI 策略)

  🔒2 开发者密码(整表编辑): 由"迷你解锁狗"生成的一次性 16 位
     密码(用一次作废一次, 软件内无秘密、无法由程序文件逆推)。
     解锁后可整表编辑 AI 安全词库与脏话词库、恢复默认。

防猜保护:
  · 一级密码连续输错 10 次 → 锁定 5 分钟; 再错 10 次 → 30 分钟;
    之后 24 小时(重启程序不清零);
  · 锁定期内输入正确密码也无效;
  · 被锁时可用开发者密码立即解锁(清零计数), 或请开发者重置。

解锁状态是会话级的: 重启程序后自动回到锁定(设计如此)。
密码只在本文档体现, 界面不会显示任何提示。

------------------------------------------------------------
  九、网络端口
------------------------------------------------------------
本程序使用的端口:
  · 9000: 向 VRChat 发送 OSC(VRChat 的默认接收端口);
  · 9001: VRChat 对外发送(本程序预留, 未使用);
  · 19190: 网页控制台(被占用时自动顺延 19191、19192…)。

高级设置 → 网络端口(零级, 无需密码):
  · OSC 发送端口: 只有当你用 VRChat 启动参数 --osc= 自定义过端口,
    或使用了 OSC 路由器时才需要改; 保存即生效, 无需重启;
  · 控制台端口: 修改后点"快速重启"生效; 页头地址会显示实际端口;
  · 端口体检: 一键检查 UDP 9000 是否被别的程序占用(并显示是哪个
    程序)、附近端口占用、VRChat OSC 状态。

提示: 如果"端口体检"显示 UDP 9000 被 VRChat 之外的进程占用,
说明有别的工具抢了 VRChat 的接收端口 —— 关掉它即可(社区常见坑)。

------------------------------------------------------------
  十、配置备份与恢复
------------------------------------------------------------
高级设置 → 常规(需一级密码):
  · 导出我的配置: 下载一个 JSON 备份(包含页面、插件设置、插件
    安全策略、授权记录; 注意里面含视觉模型 API Key, 请妥善保管);
  · 导入配置: 选择备份文件恢复; 导入后请立即点"快速重启"生效,
    重启前不要再做其它保存操作。
升级新版时: 先导出旧版配置, 装好新版再导入, 所有设置原样迁移。

------------------------------------------------------------
  十一、公开版与授权版
------------------------------------------------------------
公开版: 所有人可用; 没有一级密码, 一级/开发者设置不可用;
  插件系统完全自由(安装只需红窗确认)。

授权版(开发者申请版): 向开发者申请后发放, 压缩包里内置:
  · 你专属的八位一级密码;
  · "迷你解锁狗-你的名字"文件夹: 双击里面的 启动迷你狗.bat 会
    自动找到本程序并解锁开发者设置(每只狗只对登记的那个人有效,
    泄露只影响该人)。

申请方式: 联系开发者报上姓名, 开发者生成你的专属安装包发给你。

------------------------------------------------------------
  十二、常见问题(FAQ)
------------------------------------------------------------
Q: 头顶没字?
   A: 看状态卡圆点: 灰 = 游戏没开; 黄 = 去游戏里把 OSC 打开;
      绿但没字 = 检查功能开关是否全关、公告板是否为空;
      再不行点"一键诊断"发报告。
Q: 别人看不到?
   A: 别人得在你附近, 且他自己开着聊天框显示(游戏默认开);
      建议大家在游戏设置里打开"聊天框换行", 多行才好看。
Q: 文字被截断?
   A: VRChat 聊天框上限 144 字符 / 最多 9 行, 编辑页面时计数器
      超限会变红。
Q: 想改端口 / 轮播速度?
   A: 轮播速度在公告板卡直接改; 端口在高级设置 → 网络端口。
Q: CPU 温度显示两个杠(--)?
   A: 有些主板不提供 CPU 温度数据, 属正常, 其它数据照常。
Q: 网易云歌词不同步/整体偏慢?
   A: 看第六节: 在插件面板点「用调试端口启动网易云」一键重启,
      或退出后用"网易云音乐-歌词同步"快捷方式启动, 再点"查看状态"
      确认 CDP 已连接; 没带调试端口启动时会
      自动退回时钟估算模式(功能正常, 精度稍差)。
Q: 一级密码忘了 / 被锁了?
   A: 公开版没有一级密码(正常); 授权版被锁时等倒计时结束, 或
      用迷你狗(开发者密码)立即解锁, 或联系开发者。
Q: 桌面版任务栏图标还是默认的(Electron 图标)?
   A: ①完全退出后重启桌面版 —— 启动时窗口首帧即带正确图标;
      ②仍不对就双击程序目录的 ClearIconCache.bat 一次(清除 Windows
      图标缓存并自动重启资源管理器, 只做一次);
      ③若之前把旧图标固定过任务栏, 取消固定再重新固定一次。
Q: 插件按钮点了没反应?
   A: 插件管理完全自由、不需要密码; 若操作失败, 插件卡顶部会
      显示 ⚠ 原因, 照着提示处理即可。
Q: 截图翻译只显示原文不翻译?
   A: 翻译服务(LiveTranslate)未配置: 环境检测卡装好并开启一个
      翻译后再试; 本地 OCR 模式需要翻译服务才能翻译。
Q: 想升级新版又不想重新设置?
   A: 旧版控制台里"导出我的配置", 新版"导入配置"(见第十节)。
Q: 怎么知道出新版本了?
   A: 控制台会自动检查 GitHub 最新版(国内自动走 jsDelivr CDN,
      连不上再试 GitHub 直连), 有新版本会在日志卡版本行旁提示并
      给出下载入口; 安装包下载以群文件与 GitHub Release 为准。

------------------------------------------------------------
  十三、一键诊断与求助
------------------------------------------------------------
出问题时:
  1. 控制台状态卡点"一键诊断";
  2. 点"复制报告", 把纯文本报告发给开发者;
  3. 健康总览卡的"复制体检报告"也可以一起发。
报告里包含端口占用、插件状态、环境信息等, 开发者一眼就能定位。

==========================================
  网易云歌词精确同步(CDP)首次使用说明
==========================================

为什么需要这套东西?
--------------------
网易云客户端不向系统上报播放进度, 旧方案只能靠猜秒数(整体慢半拍、
拖动进度条就错位)。本插件 1.1 起用 CDP(开发者调试协议)直读客户端自己
显示的播放时间, 精确到秒, 拖动进度条、暂停、切歌全部自动同步。

首次使用(三步, 只做一次)
------------------------
第一步(自动部署): 运行本目录的 一键部署.bat
    会自动把插件装进 VRCLiveBoard\plugins\ 并在桌面创建
    "网易云音乐-歌词同步"快捷方式。
    (插件启用时若检测不到 CDP, 也会自动在桌面创建这个快捷方式)

第二步: 重启 VRCLiveBoard
    在控制台"插件"页启用"网易云歌词"(首次会弹红色授权窗, 点同意),
    同时确认"正在播放的歌"(SMTC)功能开着。

第三步(推荐): 插件面板里点「用调试端口启动网易云」按钮, 一键完成(会弹确认, 自动退出并重启)。桌面快捷方式仍可用作备用。

验证
----
放一首歌, 在插件面板点"查看状态":
    CDP: 已连接 进度 23s/269s   = 精确同步生效 ✓
    CDP: 未连接                 = 客户端没带调试端口启动, 回退时钟估算模式

正常启动应该看到什么
--------------------
双击快捷方式后:
  1. 弹出一个黑色命令行窗口, 显示英文提示并自动检测调试端口;
  2. 看到 [OK] CDP port 9234 active. Precise lyrics sync is ON.
     并停留几秒后自动关闭 = 成功(网易云主窗口照常打开, 看不出区别属正常);
  3. 若窗口显示 [Note] ... already running ... 并停住 = 网易云还在运行,
     先托盘右键完全退出, 再双击一次;
  4. 若显示 [WARN] CDP port not active = 启动失败, 把窗口内容截图给开发者。
最终确认: VRCLiveBoard 控制台 → 网易云歌词插件面板 → 查看状态 →
CDP: 已连接 进度 x/y。

常见问题
--------

Q: 双击快捷方式提示"检测到网易云正在运行"?
   A: 网易云是单实例程序, 已经在跑时新进程不会生效。托盘右键→退出,
      再双击快捷方式。
Q: 我不小心用普通图标启动了网易云?
   A: 没事。插件自动回退到旧模式(功能正常, 只是没精确同步),
      下次用快捷方式启动即可, 15 秒内自动重连。
Q: 调试端口安全吗?
   A: 端口只监听 127.0.0.1(本机), 外网和局域网都连不上; 只有本机
      程序能读。介意的话可在面板改端口号(启动参数也要跟着改)。
Q: 提示"未找到网易云安装(cloudmusic.exe)"?
   A: 网易云装在了自定义目录(不是默认的 Program Files)。两种办法:
      ① 保持网易云正在运行, 再点「用调试端口启动网易云」——
         1.1.3 起会按正在运行的进程自动找到真实安装位置;
      ② 在插件面板的"网易云安装路径"框里手动填 cloudmusic.exe 的
         完整路径(右键桌面网易云快捷方式→属性, 或任务管理器→
         详细信息→cloudmusic.exe→右键→打开文件所在位置, 即可找到)。
Q: 想彻底卸载?
   A: 以后用普通方式启动网易云即可; 插件在控制台停用/删除,
      桌面快捷方式删掉就行。

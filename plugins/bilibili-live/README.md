# B站直播互动(官方开放平台)

把**哔哩哔哩直播**的弹幕、礼物、醒目留言(SC)、上舰实时送上 VRChat 聊天框。

## 用法
1. 在控制台「插件」里启用本插件并授权(需要联网权限);
2. 打开插件设置, 填入四个参数(都来自 B站直播开放平台):
   - `access_key_id` / `access_key_secret`: 开放平台申请通过后的邮件里;
   - `app_id`: 在开放平台**创建互玩项目**后得到;
   - `主播身份码`: 用**开播的账号**登录 [幻星](https://play-live.bilibili.com/), 点右侧「身份码」;
3. 点「测试连接」验证参数(会 start 一次再 end 一次, 不挂长连接);
4. 启用后自动开始接收(可关)。

## 行为
- **弹幕**: `昵称: 内容`, 默认优先级 75、显示 8 秒;
- **礼物 / SC / 上舰**: 优先级 80 / 88 / 92, 显示 15 秒, **永不因排队超时被丢**;
- 手动功能(截图翻译、翻译字幕)正在显示时**让路排队**, 不打断;
- 很多人刷同一句时自动聚合: 首次照原样显示, 窗口结束补一条 `666×123`;
- 自带限流(默认两条之间至少 1.5 秒)与屏蔽词(命中替换成 `***`, 整条都被屏蔽则丢弃)。

## 安全
- 四个参数只保存在**本机** `config.json` 的插件设置里; 设置界面不回显密钥, **日志与报错都不包含密钥**;
- 网络只访问 `live-open.biliapi.com`(接口)与 `chat.bilibili.com`(弹幕长连接), 都在 manifest 里声明, 走插件权限门禁与审计;
- 只调用**官方开放平台**接口, 不使用社区逆向协议。

## 依赖与自检
- 零第三方依赖: 只用 Node 内置 `WebSocket`(需要 Node 21+, 推荐 22)、`zlib`(含 brotli)、`crypto`、`fetch`;
- **仓库里**可离线自检(不需要凭据、不联网): `node plugins/bilibili-live/test/run-all.js` —— 帧 11 + 策略 20 + 签名 24 + 连接层 16 + 事件模型 45 + 聊天框桥 50 = **166 条断言**(`test/` 不随发布包出厂)。

# B站直播互动(官方开放平台)

把**哔哩哔哩直播**的弹幕、礼物、醒目留言(SC)、上舰实时送上 VRChat 聊天框。

## 用法
1. 在控制台「插件」里启用本插件并授权(需要联网权限);
2. 打开插件设置, 填入四个参数(都来自 B站直播开放平台):
   - `access_key_id` / `access_key_secret`: 开放平台申请通过后的邮件里;
   - `app_id`: 在开放平台**创建互玩项目**后得到;
   - `主播身份码`: 用**开播的账号**登录 [幻星](https://play-live.bilibili.com/), 点右侧「身份码」;
3. 点「测试连接」验证参数(会 start 一次再 end 一次, 不挂长连接);
4. 启用后自动开始接收(可关)。

## 行为
- **弹幕**: `昵称: 内容`, 默认优先级 75、显示 8 秒;
- **礼物 / SC / 上舰**: 优先级 80 / 88 / 92, **永不因排队超时被丢**;
- **高价值"保持展示"**(设置里可开关 + 逐类时长): SC / 礼物 / 上舰会按各自配置的时长留在屏上(默认 15 秒),
  **这段时间内弹幕排队等它**, 不会被下一条弹幕顶掉; 关掉开关就回到"下一条消息过了节流就能替换"的行为。
  注意: 保持时长超过弹幕时效(默认 30 秒)时, 期间排队的弹幕会过期丢弃 —— 要保持久就同时调大 `danmakuQueueTtlMs`;
- 手动功能(截图翻译、翻译字幕)正在显示时**让路排队**, 不打断;
- 很多人刷同一句时自动聚合: 首次照原样显示, 窗口结束补一条 `666×123`;
- 自带限流(默认两条之间至少 1.5 秒)与屏蔽词(命中替换成 `***`, 整条都被屏蔽则丢弃)。

## 设置一览(控制台插件卡片里改, 保存即生效)

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| access_key_id / access_key_secret / app_id / 主播身份码 | 空 | 四个凭据(密钥类不回显, 留空保存 = 不修改) |
| 启用后自动连接 | 开 | 启用插件就自动 start |
| 忽略主播自己发的消息 | 开 | 开放平台会把你自己发的弹幕也推回来, 默认不转发 |
| 弹幕带昵称 | 开 | 关掉只显示弹幕正文 |
| 文案前缀 | 空 | 所有消息统一加前缀 |
| 两条消息最小间隔(毫秒) | 1500 | 自我保护节流 |
| 普通消息显示时长(毫秒) | 8000 | 弹幕等 |
| 高价值消息保持展示 | 开 | SC/礼物/上舰 留在屏上, 期间弹幕排队 |
| 醒目留言 / 礼物 / 上舰 保持时长(毫秒) | 15000 | 逐类可调 |
| **显示直播间标题** | 开 | 标题来自官方开播事件(打开"热度"时会用公开接口补更准的) |
| **显示房间号** | 开 | 来自官方 start 返回 |
| **显示观看热度** | 关 | **官方通道不提供热度**; 打开后用公开网页接口只读获取人气值 |
| 直播间信息前缀 / 优先级 / 刷新间隔 | 【直播间】 / 8 / 60000 | 低优先级: 只在没有别的可显示时才轮到它 |

> 直播间信息走的是程序里现成的**数据源**机制(和电脑状态/公告板一样), 不会抢弹幕的屏。

## 安全
- 四个参数只保存在**本机** `config.json` 的插件设置里; 设置界面不回显密钥, **日志与报错都不包含密钥**;
- 网络只访问 `live-open.biliapi.com`(接口)与 `chat.bilibili.com`(弹幕长连接), 都在 manifest 里声明, 走插件权限门禁与审计;
- 只调用**官方开放平台**接口, 不使用社区逆向协议。

## 依赖与自检
- 零第三方依赖: 只用 Node 内置 `WebSocket`(需要 Node 21+, 推荐 22)、`zlib`(含 brotli)、`crypto`、`fetch`;
- **仓库里**可离线自检(不需要凭据、不联网): `node plugins/bilibili-live/test/run-all.js` —— 帧 11 + 策略 20 + 签名 33 + 连接层 16 + 事件模型 59 + 聊天框桥 50 + 插件契约 33 = **222 条断言**(`test/` 不随发布包出厂)。

# VRCLiveBoard 开发者文档 - 从这里开始

**项目**: VRCLiveBoard —— VRChat OSC 工具: 电脑状态 / 正在播放 / 公告板 / 截图翻译 / 插件 显示到玩家头顶聊天框。
**制作**: DKXfox <dkxfox@qq.com> · 开发: DeepSeek 🐋
**技术栈**: Node.js(核心)+ Electron(桌面壳)+ PowerShell/Python 助手 + 网页控制台(19190 端口)。

## 快速上手(跑起来)

1. 双击 `启动.bat`(需要本机 Node)或 `启动桌面版.bat`(免环境, 桌面托盘版)。
2. 控制台打开 http://127.0.0.1:19190 (端口被占会自动 +1, 从日志里找)。
3. 游戏内 Action Menu → Options → OSC → Enabled, 聊天框即可显示。
4. 改代码后重启程序生效; 控制台页面改动只需浏览器 F5。

## 代码地图

- src/main.js — 启动编排(配置/合成器/插件管理器/网页服务)
- src/composer.js — 合成器: 优先级排序、变量渲染、144 字符截断、去重、限频
- src/osc.js — OSC 发送(UDP 127.0.0.1:9000, /chatbox/input 三参数)
- src/web/server.js — 全部 HTTP 接口(见 01)
- src/web/public/index.html — 控制台前端(单文件, 三语 i18n)
- src/ocrtranslate.js — 截图翻译(截图/OCR/视觉模型/翻译, 含防注入)
- src/helpers/screen_capture.ps1 — 截图三模式(window PrintWindow / region / screen)
- src/pluginsys/* — 插件运行时(manager/vrclog/permissions/conflicts)
- plugins/ — 随包插件(friend-welcome, scheduled-board)
- electron/main.js — 桌面壳(托盘/图标/控制台显隐)
- docs/DEV-NOTES.md — **最重要的文件**: 全部踩坑记录与决策, 继续开发前必读

## 其他人继续开发应该干什么(人)

1. **先读 docs/DEV-NOTES.md** — 里面 20+ 个坑都是真金白银踩出来的, 不读会重踩。
2. 复制项目到临时目录测试, 不要动用户正在运行的实例; 测试端口从应用日志里动态找(`http://127.0.0.1:(\d+)`)。
3. 改 PowerShell 脚本注意: PS 5.1 按 GBK 读无 BOM 文件 → .ps1 必须带 UTF-8 BOM; bat 必须 CRLF + 纯 ASCII; .NET 文件 API 不认 Set-Location, 用绝对路径。
4. 改完跑 `node --check` 和临时实例端到端测试, 再交给用户。
5. 打包分发**只在用户说"收尾"时执行**(scripts/make-dist.ps1), 平时绝对不打。
6. 配置里的密钥(视觉 API key 等)永不带入 zip, 打包脚本会自动脱敏并扫描。

## 使用 AI 工具继续开发应该干什么(AI)

1. 让 AI **先读 docs/DEV-NOTES.md 和 开发者文档 文件夹**, 再开始改代码; 会话记忆会丢, 这两个文件是唯一可靠记忆。
2. 给 AI 的指令要具体到文件: "改 src/composer.js 的 xxx" 而不是 "改一下聊天框逻辑"。
3. 让 AI 改完必须: node --check 语法检查 → 临时目录起实例 → 打接口验证 → 清理临时目录。
4. 提醒 AI: 测试别开用户的记事本/游戏窗口; 端口别写死; PowerShell 脚本注意 BOM; 不要在回复里打印用户的 API Key。
5. 新功能先要方案(用户拍板)再动手; 文案/小改动可以直接做。
6. 每次会话结束, 让 AI 把当天变更写进 DEV-NOTES.md(现状 + 新坑), 下次才能无缝接上。

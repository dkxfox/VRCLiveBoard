# 打包与分发

## 纪律(用户规定, 2026-08-24 起)
**只有用户明确发送"收尾"命令时才允许运行 make-dist 打包。** 平时开发/修 BUG 一律不打。

## 命令
```
scripts\make-dist.ps1        # PowerShell 5.1, 需 UTF-8 BOM(见下)
```
产出 dist\ 下两个 zip:
- VRCLiveBoard-Desktop-SelfContained-v*.zip — 自包含(含 Electron/Node 依赖, 免环境, ~207MB)
- VRCLiveBoard-Lite-RequiresNode-v*.zip — 精简版(需本机 Node, ~7MB)

## 打包脚本做的事
1. 完整性检查: 必需文件清单(含 plugins\friend-welcome\vendor\dist\cpexcel.js —— Excel 导入依赖, 缺了会炸);
2. 密钥扫描: sk-... / SESSDATA 命中即拦; config.json 的密钥自动脱敏后进包(工作区原文件不动);
3. 排除: 仅排除**顶层** dist/logs/node_modules/.pydist 等(用绝对路径, 别用裸名 —— 裸名 'dist' 会误杀插件自带的 vendor\dist, 历史上真炸过);
4. 打好后校验 zip 内含 cpexcel.js。

## 三个必踩的打包坑
1. **PS 5.1 GBK**: .ps1 无 BOM 时中文文件名(启动.bat)会被读成乱码 → 文件必须带 UTF-8 BOM; 编辑工具改写后会丢 BOM, 改完要用脚本补回。
2. **bat 规范**: CRLF 换行 + 纯 ASCII(中文会乱码)。
3. **.NET API 路径**: 脚本内相对路径按进程工作目录解析(不认 Set-Location), 用 $PSScriptRoot 转绝对路径。

## 图标
- 源图: 软件图标.png(1728x1728)
- scripts\make-icon.ps1 -src 软件图标.png -out electron\app.ico → 标准 7 尺寸 ICO(16~256); 单条目 ICO 会导致任务栏图标概率性回退 Electron 默认。
- 改图后: 重新生成 ico → 重启程序 → 用户任务栏取消固定/重新固定一次。

## 分发注意
- 随包插件只有 friend-welcome + scheduled-board; 其他官方插件放"官方可选插件"目录手动安装;
- zip 内 config.json 不含任何密钥;
- 版本号变更后用户升级需重新授权插件(预期)。

# 插件开发规范(v2)

插件 = plugins\ 下的一个文件夹: manifest.json + index.js(可带 vendor/、面板、页面)。

## manifest.json

```json
{
  "id": "my-plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "author": "DKXfox",
  "description": "一句话说明",
  "api": "2.0.0",
  "permissions": {
    "network": ["api.example.com"],
    "filesystem": { "read": [], "write": [] },
    "process": false,
    "ports": []
  },
  "dependencies": {},
  "conflicts": [],
  "exclusive": [],
  "loadOrder": 100
}
```

- 文件夹名必须等于 manifest.id, 否则跳过。
- api 必须是 2.x; network 是域名白名单("*" = 任意); process=true 高危(授权弹窗红字)。
- 修改版本号后, 已装用户需要重新红窗授权一次(安全设计)。

## index.js

```js
module.exports = function (ctx) {
  let timer = null;
  return {
    apply() { ctx.events.on('player.joined', onJoin); },
    dispose() { ctx.events.off('player.joined', onJoin); if (timer) clearInterval(timer); },
    api: { myMethod: async function (input) { /* 控制台可调用 */ } },
    importRows: function (rows) { /* Excel 导入入口(可选) */ },
    panel: { title: '设置', html: function (cfg) { return '...'; } },
    page: { html: function () { return '<html>...</html>'; } }
  };
};
```

ctx 能力: config(持久化设置)/ events.on/off('player.joined'|'player.left', fn) / events.every(ms,fn)→取消函数 / chatbox.send(text,{priority,ttlMs,force}) / chatbox.showSequence(chunks,{priority,eachMs,loops}) / http.request(走 network 门禁) / fs.read|write / exec.run / registerSource({id,priority,intervalMs,getText}) / plugins / logger。
所有经 ctx 的敏感调用写入 logs\plugin-audit.log 审计。

## 四个必踩的坑(官方全部踩过)

1. **call 传参**: 控制台调用插件接口时, args 对象整体作为唯一参数传入。方法入口先解包: `if (input && typeof input === 'object' && input.input) input = input.input;`
2. **模块级 ctx**: 严格模式下工厂里 `ctx = c` 未声明会 ReferenceError。模块顶部 `let ctx = null;` 再赋值, 或全用闭包。
3. **settings 断引用**: ctx.config 是引用; 运行中改配置必须原地合并(运行时已保证); 重启后 config.plugins[id] 自动回填。
4. **Node 里用 xlsx**: 浏览器版 xlsx.full.min.js 在 Node 会炸; 用 CJS 版(vendor/xlsx.js + vendor/dist/)——参考 friend-welcome。

## 官方示例

- plugins/friend-welcome — 事件 + 面板 + Excel 导入导出 + 控制台内编辑 + 进房快照跳过(1.3.0)
- plugins/scheduled-board — 定时发公告, 最简单完整示例

## 安全模型

非沙箱, 是"契约 + 门禁 + 告知": 权限清单声明 → 安装/更新时红色弹窗 + 5 秒倒计时 → 运行时越权抛错并记审计 → 冲突引擎(API 版本/依赖/互斥/同名/优先级)提示。插件可读写本机文件/发网络请求, 只装可信来源。

# 预留接口(全部在 http://127.0.0.1:19190, 端口被占自动 +1)

## 1. 聊天框推送(外部程序直接发文字)

POST /v1/chatbox (或 /api/chatbox)
请求: {"text":"要显示的内容", "priority":80, "ttlMs":8000}
说明: text 必填; priority 越高越优先(默认 80); ttlMs 为显示时长(毫秒, 默认 8 秒), 到期后恢复轮播。
限制: 游戏聊天框上限 144 字符 / 最多 9 行, 程序会自动截断。

## 2. 状态与配置

- GET /api/status — 当前显示内容、各数据源状态、变量快照、截图翻译状态
- GET /api/config — 当前配置(公告板页面/数据源/截图区域/视觉模型/语言/桌面设置)
- POST /api/config — 保存公告板 {"pages":[...], "rotationMs":8000}
- POST /api/lang — 切换控制台语言 {"lang":"zh-CN"|"zh-TW"|"en"}
- GET /api/diagnose — 一键诊断报告(远程排障核心, 直接 GET 用户实例端口即可)
- GET /api/logs?tail=200 — 运行日志尾部
- GET /api/version — 版本号

## 3. 数据源开关与优先级

POST /api/sources
{"id":"pages|hardware|media|livetranslate|ocrregion", "enabled":true, "priority":10}
说明: priority 越大越优先显示, 范围 -999~999, 实时生效并持久化。
默认梯子: 公告板 5 < 电脑状态 10 < 歌曲 30 < 字幕 40 < 截图区域 45; 插件欢迎 90 / 截图翻译 85 临时覆盖。

## 4. 截图翻译与截图区域

- POST /api/ocrtl — 触发截图翻译(倒计时→截图→识别→翻译→聊天框)。参数: {delayMs, displayMs, loops, mode: auto|vision|ocr}
- POST /api/ocrtl-vision — 配置视觉模型 {apiBase, apiKey, model, targetLang}; 本地部署免 key(localhost)
- POST /api/capture/set — 截图模式 {mode:"window"|"region"|"screen", windowTitle, region:{x,y,w,h}}
- GET /api/capture/preview — 实时全屏截图(可视化调区域用, 返回 PNG)

## 5. 插件系统

- GET /api/plugins — 插件列表(含优先级覆盖、冲突、审批状态)
- POST /api/plugins/scan — 重新扫描 plugins 目录(复制新插件文件夹后点"刷新"走的这个)
- POST /api/plugins/approve / enable / disable / remove / restart — {id}
- POST /api/plugins/import — zip 路径导入 {"path":"D:\xxx.zip"}
- POST /api/plugins/import-config — Excel 导入 {"id", "fileBase64"}
- POST /api/plugins/config — 插件设置(原地合并){"id", "cfg":{...}}
- POST /api/plugins/call — 调用插件接口 {"id", "method", "args"}。注意: args 对象会作为**唯一参数**传给插件方法, 方法入口要先解包
- GET /api/plugins/panel?id= — 插件设置面板 HTML
- GET /api/plugins/asset?id=&file= — 插件目录内静态文件(模板/库)
- GET /plugin/<id> — 插件独立页面
- GET /api/market — 市场占位(后续版本开放)

## 6. 桌面版控制

- POST /api/desktop/console — {"visible":true|false} 命令行窗口显隐(实时生效+启动时生效)
- POST /api/desktop/quit — 完全关闭(响应后 0.3 秒退出)
- POST /api/desktop/restart — 快速重启(桌面版 app.relaunch, 纯 Node 版重新 spawn)
- POST /api/devdocs/open — 用资源管理器打开"开发者文档"文件夹

## 7. 环境与自启

- GET /api/env — 环境检测(Python/LiveTranslate 等)
- POST /api/env/install-python / install-winsdk — 一键安装
- POST /api/autostart — 开机自启开关

## 8. 插件 ctx 能力(插件内可用, 详见 02)

ctx.events.on/off/every · ctx.chatbox.send/showSequence · ctx.http.request · ctx.fs.read/write · ctx.exec.run · ctx.registerSource · ctx.plugins · ctx.config · ctx.logger

## 9. 配置结构(config.json)

- sources: 按 id 分组的对象 {pages:{pages,rotationMs}, hardware:{...}, media:{...}, livetranslate:{...}, ocrregion:{...}}
- ocrtl: {delayMs, displayMs, loops, mode, vision:{apiBase,apiKey,model,targetLang}, capture:{mode,windowTitle,region}, liveTranslateDir}
- osc: {host, port, minSendIntervalMs}
- chatbox: {maxChars:144}
- web: {port, lang}
- plugins: {<id>: 插件设置(含 friend-welcome.friends 名单)}
- pluginApprovals / pluginEnabled / desktop:{showConsole} / autostart
